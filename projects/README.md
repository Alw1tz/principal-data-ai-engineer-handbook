# Projects

Production-style project placeholders. Each one gets fleshed out as its own design doc + eventually its own implementation (possibly its own repo under `~/Documents/dev/`, linked back from here).

This page is the navigational index (auto-generated below). For status ("idea" / "designing" / "building" / "shipped"), see [`../PROJECTS.md`](../PROJECTS.md) — that file tracks status by hand since it can't be derived from the filesystem; this one just lists what exists.

Add a new project with:

```bash
python3 scripts/new_project.py <slug> --title "Project Title"
```

Then add a row for it in `../PROJECTS.md`.
